# 彦根 まち歩き × 避難場所マップ

彦根市の観光の地点（182 か所。手元の試算 161 との違いは下の「試算との違い」）から、一番近い指定緊急避難場所まで徒歩で何分かを地図で見る小さなウェブ作品です。人は `app/index.html` を開き、AI エージェントは `mcp/server.mjs`（MCP の stdio）か `app/llms.txt` から同じ結果を呼べます。

## 中身

| ファイル | 役目 |
|---|---|
| `app/index.html` | 本体。1 枚の HTML。データは中に埋め込み済みなので `file://` で開いても動く。外の読み込みは cdnjs の Leaflet と OpenStreetMap のタイルだけ |
| `app/data.json` | 前処理の結果（地点・避難場所・避難所・行政界の外形・集計・出典） |
| `app/llms.txt` | AI が読む短い説明 |
| `tools/build_data.py` | `data/` の CSV と OSM から `data.json` を作り、`index.html` の埋め込みも更新する |
| `mcp/server.mjs` `mcp/README.md` | MCP サーバーと使い方（node だけ・依存なし） |
| `test/test_data.py` | 前処理・埋め込み・MCP の確かめ |
| `data/` | 材料（国土地理院の CSV 2 本・OSM の JSON・出どころの記録 `DATA_SOURCES.md`） |
| `shots/` | 画面の撮影（`_harness/` は 390px 幅を正しく撮るための撮影用の頁） |

## 作り直す・確かめる

```
python3 -I tools/build_data.py     # data.json を作り index.html に埋め込む
python3 -I test/test_data.py       # 確かめ（全部 PASS で終わる）
node mcp/server.mjs                # MCP（標準入力から JSON-RPC を 1 行ずつ）
```

## 計算の決まり

- 観光の地点: OSM の node と way のうち名前があり、tourism が attraction / museum / viewpoint / artwork、historic が castle / monument / ruins / memorial、または amenity=place_of_worship の物（relation は除く）。座標は node はそのまま、way は center。同じ名前で 30m 以内の重なりは 1 つにまとめる。
- 徒歩の分 = 直線距離（haversine）× 1.3 ÷ 分速 80m、小数 1 桁。災害ごとに、その災害に印（1）のある避難場所だけから一番近い物を選ぶ。指定避難所は印を問わず一番近い物。
- 集計は、琵琶湖の島（多景島の 3 地点）を除いた「徒歩で行ける地点」を対象にする。船でしか行けず、徒歩の分に意味がないため。
- 災害の種類は洪水・地震・土砂（崖崩れ、土石流及び地滑り）・内水氾濫。彦根市の CSV は洪水・地震・内水氾濫が 62 か所、土砂が 63 か所に印があり、ほとんど同じなので、タブを替えても数字がほぼ変わらない。

## 結果（2026-11-09 取得の材料から）

- 地点 182（徒歩で行ける 179）。避難場所まで 15 分を超えるのは 19（洪水の場合。4 災害とも同じ）。
- 一番近い避難場所までの中央値 5.1 分、指定避難所までの中央値 9.4 分。
- 佐和山の山城の跡（佐和山城の印から 600m 以内の城・史跡 5 地点）は 15.6〜17.2 分。
- 彦根城は 5.5 分（彦根市立西中学校・直線 337m）。

### 試算との違い

手元の試算は地点 161・15 分超 18・中央値 5.4 分／9.3 分・佐和山 15〜17 分でした。この作品は 182・19・5.1 分／9.4 分・15.6〜17.2 分で、地点数が 21 か所違います。

原因の候補を 1 つ確かめました（推定）。`historic=memorial` を外して作り直すと、地点 160・15 分超 18・中央値 5.4 分／9.3 分になり、試算にほぼ重なります（地点は 1 つ違い）。試算は memorial を含めなかった可能性があります。ただし指示のタグ条件に memorial があるので、この作品は含めたままにしています。含めない版にするなら `tools/build_data.py` の `HISTORIC_OK` から "memorial" を消して再実行します。

## 守ること・限界

- 国土地理院の注意 3 点（データは市町村の登録で最新でない場合がある／緊急避難場所と避難所は別物で災害ごとに指定／随時更新）と、第三者に出すときにそれが正しく伝わるようにする注意を、画面の下の箱に書いてある。注意の文は `data/DATA_SOURCES.md` の記録の趣旨に沿った言い換えで、配布 ZIP の「ご利用上の注意.txt」の原文は読んでいない。
- 道のりは直線距離からの推定。山道（佐和山など）・階段・浸水・通行止めは入っていない。
- 観光の地点は OSM に登録された物だけで、網羅ではない。同じ名前の地点が離れて 2 つあると「（2 つ目の印）」と付く（彦根城は 209262408 が 1 つ目）。
- OSM のタイルは `file://` で開くと、参照元（Referer）が付かず断られることがある。公開するときは https の頁から出す。タイルの使い方の決まり（OSM Foundation の Tile Usage Policy）は、この作業では原文を確かめていない。
- OSM の ODbL の継承条項（`data.json` に派生データベースとして入れた地点の公開条件）は確かめていない。公開前に確認が要る。
- 画面の写真・市の紋章は入れていない。城の絵は簡略化した図形。
